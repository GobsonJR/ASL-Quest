# ASL fingerspelling reference images

The 26 handshape images in this folder (`a.svg` – `z.svg`) illustrate the
American Manual Alphabet used for A–Z fingerspelling practice.

- **Source:** [wpclipart.com — American ABCs](http://www.wpclipart.com/sign_language/American_ABCs/index.html),
  redistributed via Wikimedia Commons as
  `Sign_language_A.svg` … `Sign_language_Z.svg`
  (e.g. <https://commons.wikimedia.org/wiki/File:Sign_language_A.svg>).
- **License:** Public domain (`{{PD-author}}` on Commons; wpclipart.com
  publishes its clipart as public domain). No attribution is legally
  required, but this file documents provenance for the project.
- **Modifications:** none — files are used as downloaded, only renamed to
  lowercase (`a.svg`, `b.svg`, …) to match the letter they depict.

Do not replace these with scraped or unlicensed images. If a different
source is substituted later, update this file with its license and
provenance.
